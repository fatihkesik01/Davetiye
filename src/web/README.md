# Davetiye Web

Phase 1 React/TypeScript foundation for the single responsive web application.
This directory intentionally contains no product routes or business features yet.

## Requirements

- Node.js 22.17.0
- npm 11.20.0

## Commands

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

`npm ci` uses the committed lockfile and exact package versions.
